# PolicyIK P1 本地复现：与经典 IK 控制器的公平对照（OpenArm 仿真）

- 日期：2026-11-10（CST）。证据等级：**本地实测**。原始 NPZ 位于 `outputs/p1/`，每次运行的 manifest 位于 `outputs/manifests/p1/`，逐任务结果见 `reports/p1/p1_per_task.csv`。
- 环境与 P0 相同（见 `reports/policyik_p0_summary.md`）。官方代码未做任何修改，所有对照器都放在 `tools_local/` 中。
- 预算与接口一致：同样 4,120 个评测任务，起点/目标完全相同；单次 160 步（5.33 s），30 Hz 指令；物理 60 Hz；隐式 PD（Kp 80 / Kd 4）；软限位相同。
- 指标定义与 P0 相同：
  - strict：最后 30 步平均误差 < 1 mm 且 < 0.2°。
  - coarse：< 10 mm 且 < 2°。

## 1. 实现与保真度

| 控制器 | 实现 | 与论文（附录 E/I）的对应 |
|---|---|---|
| PolicyIK | 官方 checkpoint s1/s2/s3，走 `tools_local/evaluate_ctrl.py` | 与官方 `evaluate.py` 的输出逐比特一致（max diff = 0） |
| DLS | z⁺ = z + dt·v，其中 v = argmin ‖W(Jv − k e)‖² + λ²‖v‖²，带关节上下界及指令领先界 \|z⁺ − q\| ≤ lead。W = diag(1,1,1,.2,.2,.2)，λ = 0.02 | 一致。有界最小二乘在 GPU 上用 projected-Newton 求解，与 SciPy BVLS 的差 ≤ 5e-12 |
| QP | 同上，λ = 0.005 | 一致 |
| MPC | 7 步时域，冻结 Jacobian 的运动学预测，DAQP 逐 env 求解；加速度界 100 rad/s²，平滑权重 1e-3，终端权重 1，信赖域 trust | 未实现硬件制动包络（braking envelope）和 0.2 rad/s 速度界（论文在仿真中同样不用速度界） |
| DLS (default) | Isaac Lab differential IK：q + Jᵀ(JJᵀ + 0.01² I)⁻¹ e，并截断到软限位 | 结果与论文不符，见 §6 |

- 重力前馈：经典控制器默认在每个物理子步把 `get_gravity_compensation_forces()` 写入关节力矩目标。
  - 验证：保持参考不变（hold）时，开启 FF 漂移为 0；关闭 FF 时，末端中位下垂 52 mm。
- 按论文设定，PolicyIK 不加 FF。

## 4. 部署协议（同协议，不同预算）

| 控制器 | 单次 Strict | + 校正目标 | + 8 次 transient | 累计 Coarse | E[N] |
|---|---|---|---|---|---|
| PolicyIK（3 seeds） | 93.49 | 94.79 | **98.91** | – | **1.21** |
| DLS 选定 | 52.89 | 54.15 | 76.07 | 89.95 | 3.77 |
| QP 选定 | 57.91 | 60.00 | 60.73 | 89.42 | 4.27 |
| MPC 选定 | 58.47 | 60.58 | 61.55 | 89.76 | 4.21 |

- 对经典控制器，重试主要提升 coarse；QP/MPC 的 strict 几乎不增加。
  - 原因：从 transient 偏移点出发，QP/MPC 收敛较慢（进入严门槛的中位时间为 4.1 s，PolicyIK 为 1.7 s），一次尝试内到不了 1 mm。
  - DLS 收敛更快（3.3 s），所以重试能把 strict 推到 76 %。
- 即便给经典控制器约 3.5 倍的尝试次数，它们的 strict 仍明显低于 PolicyIK 的单次结果。

## 5. 重力前馈敏感性（论文中经典控制器有 FF、PolicyIK 无 FF 这一差异的影响）

| 运行 | Strict % | Coarse % | 中位位置 mm |
|---|---|---|---|
| PolicyIK 无 FF（官方设定） | 93.49 ± 0.16 | 96.59 | 0.25 |
| **PolicyIK + FF（同一 checkpoint）** | **0.00 ± 0.00** | 2.09 ± 0.60 | 45.4 |
| DLS 选定 + FF / 无 FF | 52.89 / 23.40 | 64.64 / 32.26 | 0.80 / 55.3 |
| QP 选定 + FF / 无 FF | 57.91 / 21.24 | 64.42 / 32.35 | 0.51 / 54.1 |
| DLS default + FF / 无 FF | 55.32 / 0.00 | 59.66 / 0.02 | 0.16 / 96.1 |

- 经典控制器去掉 FF 后 strict 降为一半以下。论文给经典控制器加 FF 是在帮它们，所以对照公平性没有问题。
- **论文附录 E 写道："加上重力前馈后 PolicyIK 单次 strict 为 94.3 %"。本地用已发布的 checkpoint 复现不了，结果是 0 %。** 诊断如下：
  - 策略观测里有 d = z_{t−1} − q_t（command-state，7 维）。训练时 PD 不加 FF，静止时 d 等于保持偏置 Kp⁻¹τg(q)，例如关节 4 的中位值约为 −0.09 rad。
  - 加上 FF 后，平衡点变成 z ≈ q，d ≈ 0（实测末步 |d| 中位数 < 3e-6 rad），超出了训练分布。策略在约 40 mm 处停止推进参考，所有任务都停在 38 mm 左右。
  - 任何能让观测保持在分布内的"FF 变体"，在动力学上都与无 FF 等价，不可能把 93.5 % 提高到 94.3 %。所以论文的 94.3 % **很可能来自另一个带 FF 训练的策略**，而仓库没有发布这个 checkpoint。
  - 按计划的停止规则不重训 PPO，因此该条目记为**无法复现 / 待作者澄清**。
- 实现检查：同一个 FF 写入路径在 hold 测试和经典控制器上都工作正常，加 FF 的动作类只是在官方动作类上加了一行力矩写入，排除了 FF 实现本身有误的可能。
- 硬件含义：硬件代码库里的策略是另行训练的 FlashSAC 策略，带 FF 训练，与这里的仿真 checkpoint 不是同一个。**仿真 checkpoint 不能直接用于带重力前馈的电机层。**

## 6. 无法对齐的条目：DLS (default)

- 论文表 6 中 Isaac Lab 默认 DLS 为 1.60 % strict / 42.86 % coarse，中位误差 5.88 mm。
- 本地按附录 G 实现（λ = 0.01，全步长，以测量关节为锚点，截断到软限位，带 FF）：55.32 % / 59.66 %，中位 0.16 mm。
- 无 FF 版本为 0.00 % / 0.02 %（中位 96 mm），同样对不上。
- 该控制器的单步参考跳变很大，dz P99 达 4.9 rad，说明在奇异位形附近步长没有约束。论文的版本可能有本地未知的差异，例如 action 缩放、body offset、Jacobian 坐标系或指令频率。
- 按计划**不为了对齐而调参**，两组结果都如实列出。该条目不影响主结论：选定的 DLS/QP/MPC 都与论文对齐，且 PolicyIK 对 default 版本的优势同样显著。

## 7. 鲁棒性（超出论文范围的独立实验，结论只代表本地仿真）

### 7.1 PD 增益扰动（评测集 4,120 任务；PolicyIK 为 s1）

数值为 strict % / coarse % / 中位位置 mm。

| Kp×, Kd× | PolicyIK | PolicyIK + FF | DLS 选定 | QP 选定 |
|---|---|---|---|---|
| 0.5, 0.5 | 0.00 / 2.21 / 67.8 | 0.00 / 3.01 / 38.6 | 10.61 / 30.10 / 25.4 | 18.01 / 49.64 / 9.46 |
| 0.8, 0.8 | 1.04 / 91.04 / 4.81 | 0.00 / 2.89 / 38.5 | 34.61 / 62.69 / 3.15 | 48.71 / 64.49 / 1.03 |
| **1, 1（标称）** | **93.50 / 96.67 / 0.25** | 0.00 / 2.55 / 38.4 | 52.89 / 64.64 / 0.80 | 57.91 / 64.42 / 0.51 |
| 1.25, 1.25 | 5.34 / 94.15 / 3.44 | 0.00 / 1.92 / 38.3 | 60.00 / 64.51 / 0.23 | 58.57 / 64.44 / 0.44 |
| 2, 2 | 0.02 / 26.36 / 9.80 | 0.00 / 0.49 / 38.6 | 60.22 / 64.32 / 0.13 | 58.59 / 64.37 / 0.43 |
| 1, 0.5 | 86.41 / 92.18 / 0.36 | 0.00 / 0.78 / 40.1 | 12.77 / 35.15 / 20.2 | 20.70 / 55.80 / 6.95 |
| 1, 2 | 87.60 / 95.36 / 0.36 | 0.00 / 2.82 / 39.3 | 58.96 / 64.42 / 0.15 | 57.26 / 64.49 / 0.41 |

- **PolicyIK 的毫米级精度对刚度 Kp 极其敏感。** Kp 改变 ±20–25 % 时，strict 从 93.5 % 跌到 1–5 %，coarse 仍有 91–94 %，即仍然到达目标附近，但停在 3–5 mm 的误差上。
- 只改阻尼 Kd（×0.5 或 ×2）时，strict 仍有 86–88 %。
- 机理：
  - 标称条件下，最后 1 秒参考每步的变化量 Σ\|Δz\| 中位数为 0.0019 rad。
  - Kp ×1.25 时为 0.129 rad，Kp ×0.8 时为 0.132 rad，约大 70 倍。参考在目标附近持续抖动，误差停在 3–5 mm。
  - 策略在精细阶段依赖训练时那组 Kp 下保持偏置与 d 观测之间的固定关系。论文训练时未对执行器做随机化，因此这一点在论文中没有体现。
- 经典控制器在刚度变化下 strict 相对稳定（甚至在 Kp 增大时更好），但对阻尼减半很敏感（DLS 降到 12.8 %）。
- 对硬件迁移的含义：真实电机的等效刚度、摩擦和饱和都会偏离仿真。要靠仿真 checkpoint 达到 1 mm 精度，需要执行器随机化或在真实设备上重训；论文在硬件上正是重新训练的。

## 7.3 加长预算诊断（320 步 = 10.7 s，非论文协议，`outputs/p1/budget/`）

| 控制器 | Strict @160 步 | Strict @320 步 | Coarse @320 步 | 卡死率 @320 步 |
|---|---|---|---|---|
| PolicyIK s1 | 93.50 | 93.57 | 97.14 | 1.94 % |
| DLS 选定 | 52.89 | 63.30 | 65.61 | 34.37 % |
| QP 选定 | 57.91 | 63.71 | 65.73 | 34.25 % |

- 同一条 rollout 中第 130–160 步窗口的结果与 160 步正式评测完全相同，说明仿真是确定性的。
- 预算翻倍后，经典控制器的 strict 提高 6–10 pp，但会被约 65.7 % 的 coarse 天花板挡住，这部分就是约 34 % 的关节限位卡死，多给时间也无法解除。
- PolicyIK 在 160 步时已经收敛。
- 结论：**即使经典控制器拿到两倍时间，差距仍有约 30 pp。主因是结构性的限位卡死，而不是预算。**


## 8. 结论（G2 判定见 `reports/gate_decision.md`）

1. **论文的主结论在本地仿真中成立：** 同预算、同接口、参数独立调定的情况下，PolicyIK 的单次 strict 比 DLS/QP/MPC 高 35–41 pp（95 % CI 下界 ≥ 33.5 pp），经典控制器的失败以关节限位卡死为主；即使预算翻倍，差距仍有约 30 pp。
2. 选定经典控制器的数值、调参选择和卡死占比都与论文对齐（差距 ≤ 2.5 pp）。
3. 无法复现的两项：
   - PolicyIK + 重力前馈 94.3 %（本地为 0 %，原因是观测分布偏移，很可能需要单独训练的策略）；
   - Isaac Lab 默认 DLS 1.60 %（本地为 55.3 %）。
   两项都已如实记录，不影响主结论。
4. 新发现的风险（超出论文范围）：
   - PolicyIK 的毫米级精度依赖训练时的精确 PD 刚度：刚度偏离 5 % 时 strict 损失 14–25 pp，偏离 10 % 时损失 55–65 pp，偏离 20 % 时 strict 几乎为 0（coarse 仍保持约 96 %）；
   - PolicyIK 早期的参考跳变较大（单步 dz P99 为 1.43 rad，经典控制器为 0.17–0.23 rad），关节速度 P99 约 3.1 rad/s，部署到硬件时需要限速。
