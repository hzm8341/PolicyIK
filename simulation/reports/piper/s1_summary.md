# Piper S0（GPU 部分）与 S1 小结

日期：2026-11-11　脚本：`tools_local/policyik_piper/run_s1.sh`　原始输出：`outputs/piper/{regress,s1}/`

GPU 是与 `rsi_rl` 的作业共用的（用户 11-11 同意）；我方一次只跑一个进程。

## 门槛 PG0：通过

- 评测器的通用版是 `tools_local/evaluate_ctrl_nj.py`：把写死的 7 改成臂关节数，加了 `--robot piper`，其余不变。
  原文件 `evaluate_ctrl.py` 没有动，因为另一个会话的 Franka 流水正在用它；合并留到那边空闲时。
- OpenArm 回归（调参集 1,024 个任务，160 步）：除计时和配置字符串外，所有数组逐位比较。

| 比较 | 结果 |
|---|---|
| 原评测器跑两次（DLS k=2 lead=0.15） | 相同（说明仿真本身可重复） |
| 原评测器 对 通用版（同上） | 相同 |
| 原评测器 对 通用版（PolicyIK 官方权重 s1） | 相同 |

- `mpc.py` 没有改，通用版里遇到非 7 轴会断言退出。Piper 上不做 MPC（计划 S2 已写明）。
- Franka FK 转角门槛的原因已由另一个会话确认并提交：arccos 度量的数值问题，换 atan2 后 0.0002°。
- 数据集可重复和划分断言见 `s0_summary.md`。

## 门槛 PG1：通过

环境：`piper_reach_cfg.py`（Isaac Lab 的 reach 环境换成 Piper 右臂 USD）加 `piper_env_cfg.py`
（由官方 `env_cfg.py` 机械替换生成，方法同 Franka）。末端 body 是 `link6`；USD 没有合并固定关节；夹爪两个滑动关节在 0。

| 项目 | 结果 | 门槛 |
|---|---|---|
| FK 位置差，2,000 个构型，最大 / P99 | 0.0099 mm / 0.0080 mm | 0.1 mm |
| FK 转角差，最大 | 0.00013° | 0.01° |
| 软限位差 | 3.4e-7 rad | 1e-3 rad |
| 冒烟（DLS、QP 论文设置，1,024 个任务） | 全部为有限值 | 无 NaN |

保持测试（调参集起点，Kp 80 / Kd 4）：

| 设置 | 末端位移 P50 / P95 / 最大 |
|---|---|
| 带重力前馈，160 步 | 0.005 / 0.012 / 0.018 mm |
| 不带前馈，160 步 | 32 / 97 / 112 mm |

- 不带前馈的保持偏移主要在关节 2（最大 0.157 rad）和关节 3（0.062 rad）。
- 重力力矩最大 12.4 Nm（关节 2），仿真里力矩上限是 URDF 的 100 Nm，没有超限的构型。
  100 Nm 不是真机电机的数值，本项结论只对仿真成立。

自碰撞抽样（仿真里打开自碰撞，带前馈保持 60 步，末端被推开超过 0.1 mm 算一次）：

| 集合 | 比例 |
|---|---|
| 调参起点 1,024 | 0.49 % |
| 测试起点 4,120 | 0.68 % |

低于 OpenArm 源集合的 1.5 %，数据集不重做。实验本身按论文的做法关闭自碰撞。
碰撞体是凸包，这个比例是凸包之间的接触，不是真实外形。

## PD 增益：冻结为 Kp 80 / Kd 4

Franka 上这组增益欠阻尼，所以在 Piper 上做了同样的检查（QP，lead 0.15，调参集，160 步）：

| 设置 | 严格 % | 粗略 % | 末 30 步某关节摆幅 > 0.02 rad |
|---|---|---|---|
| k=1.5，Kd ×1 | 35.16 | 47.95 | 29.2 % |
| k=1.5，Kd ×2 | 34.96 | 48.34 | 32.1 % |
| k=1.5，Kd ×3 | 32.71 | 46.97 | 39.3 % |
| k=1，Kd ×1 | 0.00 | 39.16 | 71.3 % |

加阻尼没有改善，反而略差。Piper 上没有 Franka 那种内环欠阻尼，增益不改。
末段仍在动的任务里约 57 % 有关节贴着限位。之后所有结论只对这组增益成立。
