# 步骤 4：OpenArm 短程微调实验（重力前馈 / PD 增益随机化）

日期：2026-11-11　分支：`repro/p0-p1`　脚本：`tools_local/policyik_ft/run_ft.sh`

## 1. 目的

P1 留下两个问题：

1. 官方发布的权重在加重力前馈时严格成功率为 0 %，而论文报告 94.3 %。假设：论文那一行用的是**带前馈训练**的策略。
2. 官方权重对关节刚度极敏感（Kp 偏差 ±10 % 时严格成功率掉到 27–39 %）。问题：训练时随机化 PD 增益能否消除？

## 2. 设置

- 起点：官方权重 `checkpoints/policyik_s1.pth`（包装成完整 rl_games 检查点后续训）。
- 每个版本续训 1,000 轮 PPO，4,096 环境，学习率 1e-4，种子 1，约 9,800 万步，单次训练约 7–12 分钟。
- 运动代价直接用课程结束后的最终权重（−0.025 / −0.005），不再走课程。
- 三个版本：
  - **Base**（对照）：环境与官方训练完全一致，只是继续训。
  - **FF**：动作项打开重力前馈，其余不变。
  - **KpRand**：每次重置时按关节随机缩放刚度 U(0.8, 1.2)、阻尼 U(0.5, 2.0)。
- 评测：冻结的 4,120 个测试任务，单次尝试，160 步，指标与 P0/P1 相同。FF 版本评测时同样打开前馈。

## 3. 结果

严格 = 末 30 步平均位置误差 < 1 mm 且姿态误差 < 0.2°；粗略 = < 10 mm 且 < 2°。

|---|---|---|---|---|---|

| 官方权重 s1 | Kp ×0.9 | 27.52 | 96.14 | 1.72 | 0.120 |
| 官方权重 s1 | Kp ×1.1 | 39.32 | 96.33 | 1.23 | 0.113 |
| 官方权重 s1 | 加前馈 | 0 | — | — | — |
| **Base** | 标称 | 93.13 | 96.48 | 0.29 | 0.045 |
| Base | Kp ×0.9 | 23.33 | 95.78 | 1.71 | 0.115 |

官方权重的对照数据来自 P1 鲁棒性实验（`outputs/p1/robust/`）；官方权重在 Kd ×0.5 / ×2 下为 86.41 / 87.60 %。
P1 中官方权重的 ×0.8、×1.25 两点是 Kp 与 Kd 同时缩放（1.0 % / 5.3 %），与这里只缩放 Kp 的点不完全可比。

## 4. 结论

1. **对照组不变**：继续训 1,000 轮后 93.13 %，刚度敏感性也与官方权重一致。说明后两个版本的变化来自环境改动，而不是续训本身。
2. **前馈假设成立**：带前馈续训 1,000 轮即可从 0 % 恢复到 93.35 %，与论文的 94.3 % 相近。论文那一行很可能用的是带前馈训练的策略，而不是发布的权重。这一点可以补进给作者的 issue 草稿。
3. **带前馈的策略对刚度不敏感**：Kp ±10 % 时仍为 93.2–93.4 %。原因是前馈抵消了重力，稳态位置不再依赖 Kp⁻¹τg 这个偏移量，策略不需要在参考值里"记住"刚度。
4. **增益随机化大幅缓解但不是免费的**：Kp ±10 % 时从 27–39 % 提到 83–86 %，Kp ×0.8 / ×1.25 也有 52–58 %；代价是标称精度从 93.5 % 降到 88.4 %。粗略成功率始终约 96 %，损失只在亚毫米层面。
5. **一个反常点**：KpRand 在 Kd ×0.5 下只有 58.5 %，比官方权重的 86.4 % 更差，尽管训练时阻尼范围包含 0.5。原因未查明，可能与只训了 1,000 轮、该点在分布边界有关。

## 5. 局限

- 每个版本只有 1 个种子、1,000 轮，数字的种子间波动未知（P0 中三个官方种子的标准差约 0.16 个百分点）。
- 没有做"前馈 + 增益随机化"组合，也没有从头训练。
- 未在真机或带摩擦、延迟的模型上验证。

## 6. 复现

```bash
source env_local.sh
bash tools_local/policyik_ft/run_ft.sh        # 训练 + 评测，可断点续跑
```

权重在 `logs/rl_games/ft_{base,ff,kprand}_s1/*/nn/`，评测输出在 `outputs/ft/eval/`。
